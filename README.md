# Character Vitae
Proyecto de Semestre para Diseño Adaptable  

Ingeniería en Diseño de Entretenimiento Digital, Universidad Pontificia Bolivariana  
Prof. Andrés Bedoya Tobón

Miguel Arango, Miguel Loaiza

## What even is this?
Nuestra idea con Character Vitae es dar una forma rápida de crear una hoja de vida (CV) personalizable y versátil, pero que siga siendo rápida y simple de hacer.

## Público Objetivo
El portafolio esta enfocado en creativos, usuarios que, ademas de vidoejuegos, se centren en otros campos artisticos. Dibujo, escritura, oratoria, diseño, profesores, material didactico.
